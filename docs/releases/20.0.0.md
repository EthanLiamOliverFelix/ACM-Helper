# ACM Helper 20.0.0

安装包构建日期：2026-10-25。对应源码提交：`fc257f5267183920ee9d827ba9176d1ee4055765`。

## 题面阅读与翻译

- 修复 Codeforces 英文原文中 MathJax 渲染结果与公式源码重复显示的问题。
- PDF 题面默认展示原始 PDF，保留“提取文字”供复制与检索；提取文字的公式与排版可能不完整，请以原始 PDF 为准。
- 中文 QOJ PDF 不再展示 AI 翻译入口，也不会自动显示此前生成的译文；英文 PDF 仍可按需翻译。
- 支持译文与原文切换，并改善题面重新抓取后的翻译缓存处理。

## 题单

- QOJ 比赛导入题单时保留“通过队伍 / 提交队伍”统计，并为已有比赛题单补全缺失统计。
- 批量添加前校验题号与链接格式，跳过非法输入并汇总失败原因，避免错误匹配其他题目。
- 优化大题库批量查找，减少批量添加时界面卡顿。
- 可展开查看各 OJ 添加格式，题单三点菜单增加删除入口。

## 本地测试与终端

- CPH 编译报错直接显示到当前终端，改善终端拆分、重复创建、删除终端后无法显示报错等问题。
- 改善清屏后旧报错重新出现的问题。
- 实际输出支持折行，便于查看长数字和长文本。

## 下载与安装

- `ACM-Helper_20.0.0_2026-10-25_x64-setup.exe`：推荐一般用户使用。
- `ACM-Helper_20.0.0_2026-10-25_x64.msi`：Windows Installer 安装包。
- 两种安装包任选其一，仅支持 Windows x64。运行与调试代码所需的 G++、GDB、Python、Java 等工具需自行配置。
- `build-info.json` 提供源码提交、文件大小及 SHA-256 校验值。
