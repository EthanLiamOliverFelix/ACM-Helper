# ACM Helper 20.0.0

安装包构建日期为 2026-11-23。对应源码提交及校验值见发布附件 `build-info.json`。

## 2026-11-23 更新

- 修复新建草稿在首次自动保存后光标跳回文件开头的问题。保存时沿用当前编辑文档，保留光标位置和撤销历史。
- 将题目标签、难度筛选、分页、调试和外链按钮中的字符箭头替换为图标，改善不同字体环境下的显示。筛选箭头随展开状态旋转，题目标签的箭头调整了尺寸和对齐。

## 2026-11-22 更新

- Codeforces 题库保留尚未评级的新题，修复更新后停留在旧比赛的问题。
- 比赛卡片在读取比赛后同步题目数量，题数未知时显示“题数待读取”。
- 洛谷 C++ 提交默认开启 O2。旧版的关闭设置会升级为开启一次，之后可在设置中手动关闭。
- QOJ 手动刷新同时绕过后端页数缓存。
- AtCoder 题库请求遇到 HTTP 错误时明确反馈失败。

## 2026-11-16 更新

- Codeforces 样例保留开头、内部和结尾的空行。对于已保存的旧测试点，可以重新抓取题面后再次添加样例。
- AtCoder 题号按不区分大小写的方式匹配 AC 记录。旧记录也会计入学习题单进度，满足前置条件且完成任意一页后即可点亮知识点。
- C++ 调试器支持逐层展开结构体与嵌套容器，修复局部变量取值串位。变量监视与局部变量区域可分别折叠。

## 题面阅读与翻译

- 修复 Codeforces 英文原文中 MathJax 渲染结果与公式源码重复显示的问题。
- PDF 题面默认展示原始 PDF，保留“提取文字”供复制与检索；提取文字的公式与排版可能不完整，请以原始 PDF 为准。
- 中文 QOJ PDF 不再展示 AI 翻译入口，也不会自动显示此前生成的译文；英文 PDF 仍可按需翻译。
- 支持译文与原文切换，并改善题面重新抓取后的翻译缓存处理。

## 题单

- QOJ 比赛导入题单时保留“通过队伍 / 提交队伍”统计，并为已有比赛题单补全缺失统计。
- 批量添加前校验题号与链接格式，跳过非法输入并汇总失败原因，避免错误匹配其他题目。
- 优化大题库批量查找，减少批量添加时界面卡顿。
- 可展开查看各 OJ 添加格式，题单三点菜单增加删除入口。

## 本地测试与终端

- CPH 编译报错直接显示到当前终端，改善终端拆分、重复创建、删除终端后无法显示报错等问题。
- 改善清屏后旧报错重新出现的问题。
- 实际输出支持折行，便于查看长数字和长文本。

## 下载与安装

- `ACM-Helper_20.0.0_2026-11-23_x64-setup.exe` 适合一般用户。
- `ACM-Helper_20.0.0_2026-11-23_x64.msi` 为 Windows Installer 安装包。
- 两种安装包任选其一，仅支持 Windows x64。运行与调试代码所需的 G++、GDB、Python、Java 等工具需自行配置。
- `build-info.json` 提供源码提交、文件大小及 SHA-256 校验值。
